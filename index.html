01 / The reflected actionReal host state remains the test.

The agent sees success. The real file stays unchanged.

Agent code runs behind Linux namespaces and seccomp. A host-side governor mediates requests; it can return a reflected success without applying the write to the host. An independent observer can register the run and verify the trace it receives.

02 / Staged accessEvery door stays inside the room.

A behavior study, inside a synthetic room.

Workbench and archive resources appear at separate proposal floors. They provide no real host authority. In one informed 20-proposal pilot, the model recreated a revoked file under the same name, revealing a room-consistency flaw rather than a host escape.
