DETERMINISTIC CHECKS FOR PROBABILISTIC SYSTEMS

Chennai. Program delivery background — Amazon, Walmart. Since July 2026 I've directed coding agents to build external checks so a model or agent cannot grade its own work. I specify threat models, invariants, and pass/fail tests; agents implement. I do not independently author production security code.

Probabilistic systems should not adjudicate their own trust boundaries. Deterministic rules should. An agent's account of its own progress is untrusted until checked outside the model.

01 / the core four

System

Four parts that stay separate on purpose. Each one is coordinated, never fused, into the others.

Armoureffect / release gate

An agent proposes an action. Armour — not the agent — authorizes it, rejects it, or escalates it to a human, before any host-registered handler runs. A policy boundary, not an OS or container sandbox. Started as the safety layer inside a personal autonomous-agent project; the skeleton was later extracted into this repo. It's also the intended release gate for AI Kavach.

174 unit tests pass · all 31 modeled mutants killed

Sentryinput lint / CI

A cheap, always-on lint pass for prompt-injection and manipulation patterns — six deterministic rules: direct agent-addressing, hidden-channel instructions, scope-expansion phrasing, confirmation-bypass claims, environment and network exfiltration patterns. Runs as a CLI and in CI. Narrow and deterministic on purpose, not a governance system.

22/22 tests passing · CI across 3 Python versions
view source ↗
Reasoning Kernelclaim graph

Eight deterministic rules over a claim graph — provenance can't be faked, and a conclusion can't outrank what actually supports it. On a 24-case eval built from invented companies and people, so the model can't lean on background knowledge: 16/16 correct on resolvable claims, 8/8 honest "not enough information" answers. Two logic bugs in the kernel's own rules slipped past roughly 200 synthetic tests before a real run caught them.

16/16 + 8/8 on the 24-case invented-entity eval — not a field rate
view source ↗
Trust Boundarycoordinator

Wires Sentry, Review Board, and Reasoning Kernel together without fusing them into one confidence number. Its own docs put it plainly: these tools do not fuse into a single graph, each stays inside the boundary it was actually built and tested for. Two real integration bugs turned up while wiring it against the actual repos instead of an assumed interface — a severity check that could never fire, and code written against a Kernel method that doesn't exist.

03 / not deleted, demoted

Notebook

Prototypes, on-hold work, and experiments. Kept visible on purpose — this is where the failures live before they make it to the audit log below.

Wardenon hold
External observer for long-running coding agents. Primary matcher scores AUC 0.332 on 60 hand-labelled pairs — worse than chance. It measures vocabulary overlap, not directional alignment. source ↗
Review Boardmanual only
Six-stage deliberation gate. An auto-trigger design lost to more specific sibling skills and misfired on its own skip clause under adversarial testing — abandoned. Now a manual-only Claude Code skill; a fault-injection test confirmed it catches a planted flawed score and changes the final recommendation. source ↗
Judgeprototype
Judges one proposed action against a fixed policy, structurally unable to see the agent's stated objective — closing the hole where a dishonest agent controls both sides of an objective-similarity check. Its robustness design calls for unanimous agreement across reworded policy variants; that hasn't been run against a live model yet, only unit-level checks so far. Distinct from the JUDGE paper — same name, different artifact. source ↗
IntentGraphprototype
Detects when a conversation returns to an objective that already triggered a safety boundary, worded differently. Built for an AI Alignment Foundation fellowship application: 100% detection, 0% false-positives on 15 constructed, synthetic trajectories — its own docs call this a demonstration the mechanism works as designed, not a claim about false-positive behavior at scale. Real embedding backend failed to download (403) on two machines; runs on a lexical fallback for now. source ↗
Safety Genomelibrary
Decides whether a "repaired" candidate still carries the specific defect that got an earlier candidate rejected — by re-running the actual rule that fired, not by measuring similarity to the old failure. source ↗
Neural Node Swarmexperimental
Schema-first runtime for short-lived agent nodes: execution fires for exactly three rounds, and nothing but validated output and explicit references into persistent memory survives between them. Its own README says it plainly: not yet a production agent runtime. source ↗
Mirror Constitutionexperimental
Executable containment checks for agent sandboxes, one module per article, backed by Linux kernel-level containment (namespaces, seccomp) — a checker, not a document. A demo/test flag can disable that kernel hardening entirely, used deliberately to prove an escape succeeds without it. source ↗
